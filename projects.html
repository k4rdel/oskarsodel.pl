F1Stats 🏁

AF1Stats is an asynchronous REST API built with FastAPI. It checks the local DB for drivers or races and, if missing, fetches data from an external API, computes key metrics (avg start/end position, win percentage, pole positions, podiums), persists results to PostgreSQL and returns them to the client. The project emphasizes performance (async/await, httpx), reliability (Alembic migrations) and production readiness (Docker, rate limiting).
